# Changelog

This file records notable changes to the trendestimation library.
Candidate versions in the source tree are not necessarily published releases.

## [Unreleased]

### Added
- Blue-and-white responsive Sphinx landing page and source-derived API reference.
- Three introductory Jupyter tutorials alongside the eight-notebook research gallery.
- Preview-only Sphinx HTML workflow, with no automatic deployment.
- Eight executable scientific notebooks, a reproducibility runner, and Sphinx gallery.
- Manually triggered GitHub Pages documentation workflow and notebook-validation CI.
- MIT license and ORCID-aware software citation metadata.
- Pip and Conda development environments, repository hygiene, and contributor and security policies.
- Lightweight tests/lint CI and manually triggered package validation.

### Changed
- Updated standalone-repository installation paths, author attribution and package metadata.
- Retained version 0.1.0a0 and existing numerical routines.

## [0.1.0a0] — pre-release candidate, not published

- SVD-based finite-difference penalized least-squares smoothing.
- Conditional EDF, smoothness indices, and exact infinite-penalty endpoint.
- CV/GCV/AICc/BIC for fixed numeric reference means.
- Simulated illustrations, optional plotting, tests, and Sphinx docs.
