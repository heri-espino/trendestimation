## Editorial checks

- No title, abstract, main text, visible table or figure caption
  contains internal run names, experiment numbers, Git branches,
  full machine-specific directory paths, Actions run identifiers,
  automation instructions or unfinished handoff dialogue.
- Mathematical and empirical denominators remain explicit; within-
  seed repeated timings are not treated as independent replications.
- The numerical argument explains that spectral implementation
  success is not an identical KKT-test / high-precision certification.
- The primary recommendation is conditional on complete criterion
  selection, candidate count, valid scores and feasible dense memory.
- The paper is not a claim of a new smoothing estimator, universal
  SVD superiority, model predictive improvement or observed RAM peaks.
- Unverified author attribution in the prior draft was not retained
  as a confirmed scientific collaboration. The author must confirm
  eligibility of any coauthors, correspondent address, funding
  and competing-interest declarations before submission.
- No merging or journal submission is authorized.
