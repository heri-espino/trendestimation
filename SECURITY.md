# Security policy

## Supported versions

trendestimation is an alpha-stage candidate (0.1.0a0). No long-term
security support window or response-time guarantee has been announced.

## Reporting a vulnerability

Do not publicly disclose an exploitable vulnerability or publish secret
tokens in issues. If enabled, use the GitHub **Security → Report a
vulnerability** private reporting interface. Otherwise contact a
maintainer privately to arrange a secure reporting channel.

Include affected version or commit, reproduction steps, impact, and
mitigation ideas if known. A security fix should be independently
reviewed and include tests when feasible.
