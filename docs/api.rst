API reference
=============

The public API is organized by task below. Each function, method, and
result class is documented directly from its Python **docstring** using
Sphinx autodoc and Napoleon, rather than copied into the documentation.

For the interpretation of the bounded smoothness coordinate and
both selection APIs, start with :doc:`smoothness_coordinate`.
For selection theory, analytical derivatives, numerical inversion and verified
runnable examples, see :doc:`smoothness_optimization`. For further examples,
see :doc:`notebooks` and :doc:`gallery`.
